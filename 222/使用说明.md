# 微信群聊同步助手 · 自动监听转发版 使用说明

## 一、工具能做什么

盯住一个**源群**，把群里**任何人**发的**文字新消息**，按下面的格式自动转发到你指定的多个**目标群**：

```
来自 源群名 的 发送者 ：
--------------------------------
消息内容
```

- 只支持**文字**消息（图片、表情、文件、引用、语音等会被忽略）。
- 采用「窗口截图 → OCR 识别 → 比对新增 → UI 自动化发送」实现，不注入、不抓包。
- 仅在 Windows 上运行（依赖系统 UI 自动化）。

## 二、运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| Python | 3.8 或更高版本，安装时勾选「Add Python to PATH」 |
| 微信 | 微信电脑版（3.x / 4.x 均可），已登录 |

## 三、首次使用

### 1. 安装 Python

若电脑没有 Python，前往 [python.org/downloads](https://www.python.org/downloads/) 下载安装，**务必勾选**「Add Python to PATH」。

### 2. 启动工具

把本文件夹整个发给自己或别人，双击 **`启动.bat`**。

- 首次运行会自动检测并安装依赖库（`uiautomation`、`rapidocr-onnxruntime`、`mss`、`pillow`、`numpy`），走清华镜像，约 1～3 分钟。
- 若安装失败，按提示手动执行：
  ```
  pip install uiautomation rapidocr-onnxruntime mss pillow numpy
  ```
- 若同目录不可写，配置会自动保存到用户目录 `~/.wechat_group_sync/wechat_relay_config.json`。

> 若微信是「以管理员身份运行」的，本工具也需**以管理员身份启动**（右键 `启动.bat` → 以管理员身份运行），否则按键可能无效。

## 四、界面说明

启动后会看到如下界面：

```
┌─ 源群（被监听） ──────────────────────────────┐
│ [ 输入源群群名                                ]│
└───────────────────────────────────────────────┘
┌─ 目标群（转发到这些群，每行一个）─────────────┐
│  [ 群名列表          ]  [ 输入框 ][添加][删除]│
└───────────────────────────────────────────────┘
┌─ 选项 ────────────────────────────────────────┐
│ 识别间隔  发送间隔  发送键  演练模式          │
│ 左边距  上边距  下边距  [截图并解析(不发送)]  │
└───────────────────────────────────────────────┘
[▶ 开始监听]  [■ 停止]  [清空日志]
┌─ 运行日志 ────────────────────────────────────┐
│ ...                                            │
└───────────────────────────────────────────────┘
```

### 各字段含义

| 字段 | 说明 | 默认值 |
|---|---|---|
| 源群 | 被监听的群，群名需与微信完全一致 | 无 |
| 目标群 | 转发目的地，可多个；不能与源群相同 | 无 |
| 识别间隔 | 每隔多少秒截一次源群的图、检查新消息 | 3 秒 |
| 发送间隔 | 转发到每个目标群之间的间隔 | 4 秒 |
| 发送键 | 微信发送消息用 Enter 还是 Ctrl+Enter | Enter |
| 演练模式 | **只识别并打印，不真正发送** | 开启 |
| 左边距 / 上边距 / 下边距 | 截图识别区域的裁剪边距（像素） | 320 / 100 / 155 |

## 五、使用步骤

1. **填源群**：在「源群」输入框里填入要监听的群名。
2. **填目标群**：逐个「添加」目标群，或用「批量导入」一次粘贴多行群名。
3. **先演练**：保持「演练模式」勾选，点「开始监听」。观察日志，确认能正确识别源群的新消息。
4. **正式转发**：取消「演练模式」，再次「开始监听」。
5. **停止**：点「停止」即可。

## 六、如何获得准确的群名

群名必须和微信里**完全一致**，否则工具找不到群。获取方式：

- 在微信里打开该群，**聊天顶部标题**显示的就是群名，直接照抄。
- 或右键群聊 → 群聊名称 → 复制。

注意：

- 短名字（如 `111`、`222`）必须**完全一致**，避免 `111` 误匹配到 `1111`。
- 长名字允许 1 个字符的 OCR 误差（如 `TruthAI` 被识别成 `TruthAl` 也能匹配）。
- 若群被改名或解散，搜索结果里不会出现该群，工具会跳过并在日志提示「无法定位会话」。

## 七、识别区域边距调整

如果日志里识别不到消息，或把别的区域文字当成了消息，可能需要调整三个边距（像素值）：

- **左边距**：消息区左边界离窗口左边的距离。微信 4.x 默认约 320。
- **上边距**：消息区顶部离窗口顶部的距离。默认 100。
- **下边距**：消息区底部离窗口底部的距离，需避开输入框。默认 155。

可点「截图并解析（不发送）」按钮，查看当前参数下识别出的文字，据此微调。

## 八、工作原理与安全说明

- 每轮开始会先校验当前是否在源群（OCR 读取聊天标题），不在则不截图。
- 搜索群时**只点「群聊」和「最常使用」分区**，绝不点「联系人」「聊天记录」，避免发到同名个人聊天。
- 点进群后再次 OCR 校验标题，标题不符就返回重试；3 次失败则**跳过该群，绝不盲发**。
- 去重机制：同一条消息（按「发送者+内容」去空白小写后比对）只转发一次。

## 九、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 日志提示「无法定位会话 XXX」 | 群名不一致、群已改名/解散。请核对群名。 |
| 按键无效、发送不出去 | 微信以管理员运行但工具没提权；用管理员身份启动。 |
| 识别不到任何消息 | 调整识别区域边距；或源群消息区被其他窗口遮挡。 |
| 消息重复转发 | 同一条消息被 OCR 成了不同文本；一般去重机制会过滤，偶发可忽略。 |
| 转发到了错误的群 | 群名与多个群相似；请确保群名唯一。 |
| 第一次启动很慢 | 在自动下载 OCR 模型（约 30MB），之后会很快。 |

## 十、风险提示

- 微信个人号没有开放接口，本工具属于客户端自动化操作。
- 请**低频、少量**使用，避免账号被风控。
- 监听期间**不要手动操作微信窗口**，工具会反复切换会话。
- 首次转发前务必先跑一轮「演练模式」确认效果。
